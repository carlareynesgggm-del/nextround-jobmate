# NextRound Career Hub

Construye NextRound según la especificación detallada del usuario: SaaS premium, desktop-first y responsive para centralizar la búsqueda de empleo. Prioriza una UI excelente y coherente, navegación, tracking de candidaturas, páginas de detalle con tabs y stages, CV Vault, calendario, notas, tareas y analytics. Habilita Lovable Cloud primero para autenticación por email, datos persistentes privados por usuario, almacenamiento de documentos y relaciones escalables. Incluye datos demo de Carla con las empresas, estados, KPIs y eventos indicados. Implementa la V1 de forma modular, sin AI, scraping, Gmail ni automatizaciones.
